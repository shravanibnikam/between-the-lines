# Typewriter sounds

`typewriter.wav` holds every sound of typewriter mode. It is cut from two recordings:

- The keystrokes, key releases and carriage return come from
  [WWS Typewriter](https://commons.wikimedia.org/wiki/File:WWS_Typewriter.ogg), a 1940 Erika 5
  mechanical typewriter, by Work With Sounds / Konrad Gutkowski, licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- The bell is [typewriter-ding-near-mono](https://freesound.org/people/_stubb/sounds/406243/) by
  _stubb, under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Changes: single sounds were cut out (keystrokes at 1.116, 4.888, 5.275, 6.708, 7.365, 9.980,
13.266, 14.039, 16.779 and 17.926 s; releases at 3.087, 8.024, 8.961, 9.786, 10.886 and
12.904 s; the carriage return from 20.47 to 21.80 s), mixed to mono, faded, levelled and joined
into one 16-bit, 44.1 kHz file. Where each one sits in it is listed in `../keysound.ts`.
